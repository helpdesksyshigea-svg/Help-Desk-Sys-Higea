# Help Desk SYS HIGEA

Sistema de tiquetes para que Facturación del E.S.E. Hospital Orito solicite y controle
eliminaciones de laboratorios, facturas e historias clínicas gestionadas por el proveedor
SYS HIGEA, con aprobación previa, plazos (ANS) y trazabilidad.

> Este repositorio es **público**. Nunca se debe subir aquí información de pacientes,
> credenciales, archivos `.env` ni volcados de base de datos.

## Estructura

- `db/` — esquema SQL y datos semilla (Postgres / Supabase).
- `api/` — backend (Node.js + Express).
- `web/` — frontend (React).
- `docs/` — documentación de traspaso y decisiones.

## Estado

En desarrollo. Ver `docs/` para el plan de fases y el documento de traspaso original.
